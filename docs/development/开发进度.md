**可用命令**:
- `test` - JMeter数据收集
- `run` - 同步执行JMeter和nmon（推荐）
- `report` - Excel报告生成
- `all` - 压测+报告一键执行
- `distributed` - 分布式压测（按配置启用）

**使用示例**:
```bash
# 推荐：脚本入口
jmeter-test-suite run
jmeter-test-suite report

# 备用：python -m
python -m jmeter_test_suite run
python -m jmeter_test_suite report
```
