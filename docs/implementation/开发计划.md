# v1.0 开发计划

## 🎯 概述

JMeter和nmon性能测试数据收集与Excel报告生成工具v1.0的开发计划，专注于基础功能实现，简单直接。

## 📋 开发目标

### v1.0 核心功能
1. **JMeter数据收集** - 执行测试，收集性能数据
2. **nmon数据收集** - 通过SSH连接服务器，收集系统资源数据
3. **Excel报告生成** - 整合JMeter和nmon数据，生成Excel报告

### 1. JMeter命令构建
```python
def build_jmeter_command(jmx_file, threads, loops, output_dir):
    jtl_file = os.path.join(output_dir, "result.jtl")
    html_dir = os.path.join(output_dir, "report")
    
    cmd = [
        "jmeter",
        "-n", "-t", jmx_file,
        "-l", jtl_file,
        "-e", "-o", html_dir,
        "-Jthreads", str(threads),
        "-Jloops", str(loops)
    ]
    return cmd
```
