## 📋 版本概述

v5.0.0是一个大版本迭代，主要聚焦于Git历史清理和项目性能优化。本次更新清理了Git历史中的大文件（总计1156MB），使.git目录从1333MB降至8.48MB，大幅提升了项目的克隆速度和操作性能。
