# 切换到清华镜像源 - 详细SSH命令

## 步骤1：杀掉当前yum进程

```bash
# 查看正在运行的yum进程
ps aux | grep yum | grep -v grep

# 强制杀掉所有yum进程
pkill -9 yum

# 等待2秒确保进程已终止
sleep 2

# 再次确认没有yum进程
ps aux | grep yum | grep -v grep || echo "无yum进程"
```

## 步骤2：备份现有配置

```bash
# 备份现有yum仓库配置
mkdir -p /etc/yum.repos.d/backup
cp -r /etc/yum.repos.d/*.repo /etc/yum.repos.d/backup/

# 查看备份的文件
ls -la /etc/yum.repos.d/backup/
```

## 步骤3：配置清华镜像源

```bash
# 创建清华镜像源配置文件
cat > /tmp/tsinghua.repo << 'EOF'
[baseos]
name=CentOS Stream $releasever - BaseOS - mirrors.tuna.tsinghua.edu.cn
baseurl=https://mirrors.tuna.tsinghua.edu.cn/centos-stream/$stream/BaseOS/$basearch/os/
gpgcheck=1
enabled=1
gpgkey=file:///etc/pki/rpm-gpg/RPM-GPG-KEY-centosofficial

[appstream]
name=CentOS Stream $releasever - AppStream - mirrors.tuna.tsinghua.edu.cn
baseurl=https://mirrors.tuna.tsinghua.edu.cn/centos-stream/$stream/AppStream/$basearch/os/
gpgcheck=1
enabled=1
gpgkey=file:///etc/pki/rpm-gpg/RPM-GPG-KEY-centosofficial

[extras-common]
name=CentOS Stream $releasever - Extras packages - mirrors.tuna.tsinghua.edu.cn
baseurl=https://mirrors.tuna.tsinghua.edu.cn/centos-stream/SIGs/$stream/extras/$basearch/extras-common/
gpgcheck=1
enabled=1
gpgkey=file:///etc/pki/rpm-gpg/RPM-GPG-KEY-centosofficial

[epel]
name=EPEL $releasever - $basearch - mirrors.tuna.tsinghua.edu.cn
baseurl=https://mirrors.tuna.tsinghua.edu.cn/epel/$releasever/Everything/$basearch
enabled=1
gpgcheck=1
gpgkey=https://mirrors.tuna.tsinghua.edu.cn/epel/RPM-GPG-KEY-EPEL-$releasever
EOF

# 查看创建的配置文件
cat /tmp/tsinghua.repo
```

## 步骤4：替换现有配置

```bash
# 移动所有现有repo文件到备份目录
mv /etc/yum.repos.d/*.repo /etc/yum.repos.d/backup/ 2>/dev/null

# 复制清华镜像配置
cp /tmp/tsinghua.repo /etc/yum.repos.d/

# 验证配置已安装
ls -la /etc/yum.repos.d/

# 查看配置内容
cat /etc/yum.repos.d/tsinghua.repo
```

## 步骤5：清理并重建缓存

```bash
# 清理yum缓存
yum clean all

# 重建yum缓存（使用清华镜像源）
yum makecache
```

## 步骤6：验证镜像源

```bash
# 查看当前使用的仓库
yum repolist

# 查看仓库详细信息
yum repoinfo
```

## 步骤7：安装EPEL和ntfs-3g

```bash
# 安装EPEL仓库（从清华镜像）
yum install -y epel-release

# 清理缓存
yum clean all

# 重建缓存
yum makecache

# 安装ntfs-3g
yum install -y ntfs-3g

# 验证安装
rpm -q ntfs-3g
```

## 步骤8：挂载移动硬盘

```bash
# 检查USB设备
lsblk /dev/sda

# 检查文件系统类型
blkid /dev/sda1

# 创建挂载点
mkdir -p /media/usb_drive

# 挂载移动硬盘
mount -t ntfs-3g -o uid=1000,gid=1000,umask=0002 /dev/sda1 /media/usb_drive

# 验证挂载
df -h /media/usb_drive

# 显示挂载信息
mount | grep sda1

# 测试访问
ls -la /media/usb_drive | head -20
```

## 一键执行版本（按顺序复制粘贴）
