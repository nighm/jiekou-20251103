# 为什么Python脚本中无法显示yum进度条的原因

## 问题现象

在SSH终端中执行`yum makecache`或`yum install`时，可以看到实时进度条：
```
[=== ] --- B/s | 0 B --:-- ETA
```

但在Python脚本中执行时，看不到这些进度条，只能看到最终结果。

## 根本原因

### 1. **TTY/PTY问题**（主要原因）

**问题**：
- yum的进度条需要**伪终端（PTY）**才能正确显示
- Python的`paramiko.SSHClient.exec_command()`默认**不使用PTY**
- 没有PTY时，程序认为输出不是交互式的，不会显示进度条

**技术细节**：
```python
# 默认方式（无PTY）
ssh.exec_command("yum install xxx")
# 输出：只有最终结果，没有进度条

# 使用PTY的方式
chan = ssh.get_transport().open_session()
chan.get_pty(width=120, height=40)  # 分配PTY
chan.exec_command("yum install xxx")
# 输出：可以看到进度条
```

### 2. **输出缓冲问题**

**问题**：
- yum的输出可能被缓冲
- 进度条使用`\r`（回车）覆盖同一行
- 缓冲导致输出延迟，进度条效果丢失

**解决方案**：
```python
# 设置无缓冲
import sys
sys.stdout = sys.stdout.__class__(sys.stdout.buffer, encoding='utf-8', line_buffering=True)
```

### 3. **ANSI转义码处理**

**问题**：
- 进度条使用ANSI转义码（如`\033[2K`清除行，`\033[1A`上移光标）
- 非交互式终端可能不处理这些转义码
- 即使读取了，显示时也可能被过滤

### 4. **stdout vs stderr**

**问题**：
- yum的进度条输出到**stderr**，不是stdout
- 如果只读取stdout，会错过进度条

**解决方案**：
```python
chan.set_combine_stderr(True)  # 合并stderr到stdout
```

## 解决方案

### 方案1：使用PTY（推荐）

```python
def execute_with_pty(ssh, command):
    """使用PTY执行命令，可以看到进度条"""
    chan = ssh.get_transport().open_session()
    chan.get_pty(width=120, height=40)  # 分配PTY
    chan.set_combine_stderr(True)  # 合并stderr
    chan.exec_command(command)
    
    # 实时读取输出
    while True:
        if chan.recv_ready():
            chunk = chan.recv(4096).decode('utf-8', errors='ignore')
            sys.stdout.write(chunk)
            sys.stdout.flush()
        if chan.exit_status_ready():
            break
        time.sleep(0.05)
    
    exit_status = chan.recv_exit_status()
    chan.close()
    return exit_status
```

### 方案2：强制yum显示详细输出

```python
# 使用-v参数显示详细信息
yum -v install -y ntfs-3g

# 或者禁用进度条，显示详细输出
yum --setopt=progressbar=0 install -y ntfs-3g
```

### 方案3：使用expect或pexpect

```python
import pexpect

child = pexpect.spawn('ssh root@192.168.24.45')
child.expect('password:')
child.sendline('1')
child.sendline('yum install -y ntfs-3g')
child.interact()  # 交互式显示
```

## 完整解决方案代码

```python
#!/usr/bin/env python
# -*- coding: utf-8 -*-
import paramiko
import sys
import time

def execute_with_full_output(ssh, command):
    """使用PTY执行命令，完整显示所有输出包括进度条"""
    chan = ssh.get_transport().open_session()
    chan.get_pty(width=120, height=40)  # 关键：分配PTY
    chan.set_combine_stderr(True)  # 合并stderr
    chan.exec_command(command)
    
    # 实时读取并显示
    while True:
        if chan.recv_ready():
            chunk = chan.recv(4096).decode('utf-8', errors='ignore')
            sys.stdout.write(chunk)
            sys.stdout.flush()  # 立即刷新
        if chan.exit_status_ready():
            break
        time.sleep(0.05)
    
    # 读取剩余输出
    while chan.recv_ready():
        chunk = chan.recv(4096).decode('utf-8', errors='ignore')
        sys.stdout.write(chunk)
        sys.stdout.flush()
    
    exit_status = chan.recv_exit_status()
    chan.close()
    return exit_status

# 使用示例
ssh = paramiko.SSHClient()
ssh.set_missing_host_key_policy(paramiko.AutoAddPolicy())
ssh.connect(hostname='192.168.24.45', username='root', password='1')

execute_with_full_output(ssh, "yum makecache")  # 可以看到进度条
execute_with_full_output(ssh, "yum install -y ntfs-3g")  # 可以看到进度条
```

## 总结

**为什么看不到进度条**：
1. ❌ 没有使用PTY（伪终端）
2. ❌ 输出被缓冲
3. ❌ 只读取了stdout，没有读取stderr
4. ❌ ANSI转义码被过滤

**如何解决**：
1. ✅ 使用`chan.get_pty()`分配PTY
2. ✅ 设置`set_combine_stderr(True)`合并stderr
3. ✅ 实时读取并立即刷新输出
4. ✅ 使用`sys.stdout.flush()`强制刷新
