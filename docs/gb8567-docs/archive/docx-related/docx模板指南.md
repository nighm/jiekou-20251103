# 参考DOCX模板创建指南

## 📋 概述

参考DOCX模板是Pandoc转换Markdown到DOCX的关键文件。它定义了转换后DOCX文档的所有格式细节，包括字体、字号、行距、页边距、标题样式等。

**重要**：只有创建了符合GB/T 8567-2006标准的参考DOCX模板，转换后的文档才能符合格式要求。

## 🎯 创建步骤

### 步骤1：创建新的Word文档

1. 打开Microsoft Word（或WPS Office）
2. 创建新文档
3. 另存为：`templates/reference.docx`

### 步骤2：设置页面格式

1. 点击 **布局** → **页边距** → **自定义边距**
2. 设置：
   - 上：2.5cm
   - 下：2.5cm
   - 左：2.5cm
   - 右：2.5cm
3. 点击 **纸张**，选择：**A4**
4. 点击 **确定**

### 步骤3：设置正文样式（Normal）

1. 点击 **开始** → **样式** → **正文**（右键）→ **修改**
2. 设置格式：
   - **字体**：
     - 中文字体：宋体
     - 西文字体：Times New Roman
     - 字号：小四号（12pt）
   - **段落**：
     - 行距：1.5倍行距
     - 段前：0pt
     - 段后：6pt
     - 对齐方式：两端对齐
3. 点击 **确定**

### 步骤4：设置一级标题样式（Heading 1）

1. 点击 **开始** → **样式** → **标题1**（右键）→ **修改**
2. 设置格式：
   - **字体**：
     - 中文字体：黑体
     - 西文字体：Arial
     - 字号：三号（16pt）
     - 字形：加粗
   - **段落**：
     - 行距：单倍行距
     - 段前：12pt
     - 段后：6pt
     - 对齐方式：左对齐
3. 点击 **确定**

### 步骤5：设置二级标题样式（Heading 2）

1. 点击 **开始** → **样式** → **标题2**（右键）→ **修改**
2. 设置格式：
   - **字体**：
     - 中文字体：黑体
     - 西文字体：Arial
     - 字号：四号（14pt）
     - 字形：加粗
   - **段落**：
     - 行距：单倍行距
     - 段前：6pt
     - 段后：6pt
     - 对齐方式：左对齐
3. 点击 **确定**

### 步骤6：设置三级标题样式（Heading 3）

1. 点击 **开始** → **样式** → **标题3**（右键）→ **修改**
2. 设置格式：
   - **字体**：
     - 中文字体：黑体
     - 西文字体：Arial
     - 字号：小四号（12pt）
     - 字形：加粗
   - **段落**：
     - 行距：单倍行距
     - 段前：6pt
     - 段后：3pt
     - 对齐方式：左对齐
3. 点击 **确定**

### 步骤7：设置表格样式（可选）

1. 插入一个表格（2行2列）
2. 选中表格，点击 **表格工具** → **设计** → **表格样式**
3. 选择或创建表格样式：
   - 边框：实线、0.5pt、黑色
   - 表头：加粗、居中
   - 表格字体：宋体、五号（10.5pt）
   - 单元格对齐：垂直居中
4. 删除测试表格

### 步骤8：设置页眉页脚

#### 8.1 设置页眉

1. 双击页眉区域，进入页眉编辑模式
2. 输入：`文档名称 - 版本号`
3. 格式：
   - 字体：宋体、五号（10.5pt）
   - 对齐：右对齐
4. 关闭页眉编辑

#### 8.2 设置页脚

1. 双击页脚区域，进入页脚编辑模式
2. 插入页码：
   - 点击 **插入** → **页码** → **页面底端** → **普通数字2**（居中）
3. 格式：
   - 字体：宋体、五号（10.5pt）
   - 对齐：居中
4. 关闭页脚编辑

### 步骤9：保存模板

1. 确保所有样式都已设置完成
2. 点击 **文件** → **另存为**
3. 选择位置：`templates/reference.docx`
4. 文件类型：**Word文档 (.docx)**
5. 点击 **保存**

## ✅ 验证模板

### 验证步骤

1. **创建测试文档**：
   ```markdown
   # 一级标题
   
   这是正文内容。
   
   ## 二级标题
   
   这是正文内容。
   
   ### 三级标题
   
   这是正文内容。
   
   | 列1 | 列2 |
   |-----|-----|
   | 数据1 | 数据2 |
   ```

2. **转换为DOCX**：
   ```bash
   pandoc test.md -o test.docx --reference-doc=templates/reference.docx
   ```

3. **检查格式**：
   - [ ] 正文字体：宋体、12pt
   - [ ] 行距：1.5倍
   - [ ] 页边距：2.5cm
   - [ ] 一级标题：黑体、16pt、加粗
   - [ ] 二级标题：黑体、14pt、加粗
   - [ ] 三级标题：黑体、12pt、加粗
   - [ ] 表格格式：边框、对齐正确
   - [ ] 页眉页脚：正确显示

## 🔧 高级设置

### 设置多级列表样式

如果需要支持多级列表：

1. 点击 **开始** → **多级列表** → **定义新的多级列表**
2. 设置各级列表格式：
   - 一级：1. 2. 3.
   - 二级：1.1 1.2 1.3
   - 三级：1.1.1 1.1.2 1.1.3
3. 设置字体和格式（与正文一致）

### 设置代码块样式

如果需要代码块样式：

1. 创建新样式：**代码**
2. 设置格式：
   - 字体：Consolas（等宽字体）
   - 字号：五号（10.5pt）
   - 背景色：浅灰色（RGB: 240, 240, 240）
   - 边框：实线、0.5pt

### 设置引用样式

如果需要引用样式：

1. 创建新样式：**引用**
2. 设置格式：
   - 字体：与正文一致
   - 字号：与正文一致
   - 段落：左缩进2字符
   - 边框：左边框、2pt、灰色

## ⚠️ 注意事项

1. **样式名称必须正确**：
   - 正文样式必须命名为 `Normal`
   - 标题样式必须命名为 `Heading 1`、`Heading 2`、`Heading 3`
   - Pandoc会根据样式名称映射Markdown元素

2. **字体必须安装**：
   - 确保系统中安装了宋体、黑体、Times New Roman、Arial
   - 如果缺少字体，转换后的文档可能格式不正确

3. **保存格式**：
   - 必须保存为 `.docx` 格式（不是 `.doc`）
   - Pandoc不支持旧版Word格式

4. **模板位置**：
   - 建议放在 `templates/reference.docx`
   - 转换脚本默认使用此路径
